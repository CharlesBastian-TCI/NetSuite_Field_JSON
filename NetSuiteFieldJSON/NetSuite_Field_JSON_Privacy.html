NetSuite Field JSON Privacy Policy

Last updated: May 2, 2026

Summary

NetSuite Field JSON does not collect, sell, transmit, or store user data. The extension reads record data from the active NetSuite tab only after the user opens the extension, and it displays that data locally in the extension popup.

Data Collection

The extension does not collect personal information, authentication credentials, browsing history, analytics events, or usage telemetry.

Data Use

Record data is used only to render a local JSON view for the user. The extension does not send record data to Technocrat Consulting Inc., Oracle, analytics providers, advertising networks, or any other third party.

Data Storage

The extension does not save NetSuite record data to extension storage, local storage, cookies, or external servers.

Permissions

  • activeTab: grants temporary access to the active NetSuite tab after the user opens the extension.
  • scripting: runs a user-invoked script in the active NetSuite page so SuiteScript 2.1 can read the current record.
  • declarativeContent: enables the extension action only on NetSuite application pages.

Contact

Questions can be sent to Client_Support@TechnocratConsultingInc.com.
