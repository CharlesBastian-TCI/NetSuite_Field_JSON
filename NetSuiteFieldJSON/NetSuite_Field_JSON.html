NetSuite Field JSON

A focused Chrome extension for viewing NetSuite records as searchable JSON, with SuiteScript 2.1 extraction first and page XML fallback when scripting is unavailable.

Chrome Web Store Privacy Support

What It Does

NetSuite Field JSON opens from a NetSuite record page and renders the record data in a filterable JSON view. It is built for administrators, developers, consultants, and power users who need to inspect field IDs, field values, sublists, and record metadata without building a one-off script.

SuiteScript First

Uses SuiteScript 2.1 in the active NetSuite page when Chrome scripting permission is available.

XML Fallback

Falls back to the NetSuite page XML view when scripting is unavailable or blocked.

Searchable Output

Formats the result as JSON and filters the visible output as you type.

Reference Links

Includes quick links to the REST API Browser and Records Catalog for supported record types.

How To Use

  • Open a NetSuite record page.
  • Click the NetSuite Field JSON extension icon.
  • Wait for the record to load, then search or scroll through the JSON.
  • Use the footer links to jump to NetSuite documentation for the current record type.

Permissions

The extension uses a small set of Chrome permissions so it can run only when the user opens it on a NetSuite page.

  • activeTab: gives the extension temporary access to the active NetSuite tab after the user clicks the extension.
  • scripting: allows the extension to run a small, user-invoked script in the active NetSuite page to read the record through SuiteScript 2.1.
  • declarativeContent: enables the extension icon only on NetSuite application pages.

Privacy

NetSuite Field JSON does not collect, sell, transmit, or store user data. Record data is read from the active NetSuite page only after the user opens the extension, and the result is displayed locally in the extension popup.

The extension does not include analytics, remote logging, advertising trackers, or external data services.
